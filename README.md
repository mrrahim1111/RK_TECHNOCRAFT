> **"Grow Beyond the Classroom."**

## 💻 Website Tech Stack & Architecture

This repository contains the official corporate website for **RK TECHNOCRAFT**:

- **Framework:** [Next.js](https://nextjs.org/) 16 (React 19, App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict type-safety)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) v4 with custom brand tokens
- **Visuals & 3D:** Interactive Three.js canvas (`Hero3D`), physics-based cursor spotlight tracking (`InteractiveCard`), and 3D micro-tilt perspective
- **Icons:** [Lucide React](https://lucide.dev/)
- **API Routes:** Serverless Next.js Route Handlers (`/api/contact`) with validation and structured payload dispatch

### Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/rahim-technocraft/website.git
cd website\(RKTC\)

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Compile optimized production bundle using webpack
npm run build -- --webpack

# Start production server
npm start
```
